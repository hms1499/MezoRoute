# U14 Flow Fit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every flow page renders two columns at the Dashboard's page width with an aside of facts it already reads, and six product faults are fixed: the Leverage zero note, the primary below the fold, field errors, the 404, titles and share cards, and the empty Stability Pool withdraw.

**Architecture:**
- `FlowColumn` always renders Positions' grid (`lg:grid-cols-3`, the card `lg:col-span-2`). The 520 px column, `FlowPage`, and `isFlowPath` are deleted.
- Early-return states (loading, error, connect, no executor) go through a new `FlowState` wrapper, so they keep the card's edge and width.
- Asides are built from pure row helpers (`src/lib/flow/sign-facts.ts` and per-page view helpers) so they are unit-tested without wallet providers.
- Per-route metadata comes from server segment `layout.tsx` files, because every `page.tsx` is a client module.

**Tech Stack:** Next.js 14.2.35 static export, React 18.3.1, Tailwind 3.4, Vitest 5, Playwright (QA only).

**Spec:** `docs/superpowers/specs/2026-11-10-u14-flow-fit-design.md`

## Global Constraints

- Branch `feat/u14-flow-fit`. Code, comments, commits, and docs in English. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- The gate is `cd frontend && npm test && npm run build`, and every existing guard must stay green: `layout`, `colour-roles`, `design-doc`, `typography`, `heading-guard`, `control-guard`, `spacing-guard`, `radius-guard`, `icon-guard`, `motion-guard`, `palette-guard`.
- No contract, quote, gate order, transaction payload, or snapshot read changes. Asides use only what the page's snapshot already holds.
- One accent (primary) button per view. Risks never render after Sign below `lg` (1024 px).
- The grid is exactly `grid grid-cols-1 gap-4 lg:grid-cols-3 lg:items-start`, with the card `lg:col-span-2`, the Positions grid.
- Staking copy always says swap fees go to veBTC voters. The Stability Pool never shows a rate or "earn".
- Titles are static metadata (never set from client JS). The template is `"%s | MezoRoute"` and `metadataBase` is `https://mezoroute.vercel.app`.
- Constants: `ORACLE_BOUND_DEFAULT_BPS` 500n, `PRICE_IMPACT_LIMIT` 5% (unchanged), new `PRICE_IMPACT_WARN = 10_000_000_000_000_000n` (1%).
- No `npm run ui-audit`. QA is the targeted Playwright measurement in Task 13.

## Review Focus

1. **A wallet-less visitor on `/route/lp/`.** The aside still shows the comparison and Before you sign from the zero-address snapshot, and no row reads as their balance. → Task 1 test `lpSignFacts` takes no account.
2. **A network with `executor` or `leverage` null.** The sign-facts helper returns `null`, the aside omits the panel, and the page does not crash. → Tasks 1 and 6 tests.
3. **A smart account (Bitcoin wallet).** The LP exit facts say "exact approval" instead of "LP permit", and the Trove facts say Trove actions are EVM wallets only. → Task 1 test.
4. **Exactly 1024 px (the `lg` boundary) and 360 px.** Two columns at 1024 with no horizontal scroll; one column at 1023 and 360. → Task 13 QA measures 1023 and 1024 as well.
5. **A Leverage zero whose binding limit changes between refetches.** The note follows `limitedBy` each render and never shows the floor sentence for an oracle zero. → Task 8 test with the BORROWER shape and a floor-zero shape.
