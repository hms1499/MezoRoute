# U20 Trove Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/trove/` page (with a Trove; without a Trove or wallet) shaped after Liquity V2's loan screen, a Trove header tab, and a Dashboard Trove card that becomes a summary leading to it.

**Architecture:** Pure maths and view models in `src/lib/trove/` (risk levels, drift, multiply view, page view) and `src/lib/leverage/` (snapshot read, smallest open); React views in `src/components/trove/`. The page reads `useTroveSnapshot` (now wallet-optional, zero address when unconnected) and its redemption queue; nothing new is written on chain.

**Tech Stack:** Next 14 static export, React 18, wagmi 2.19.5, viem 2.57.2, TanStack Query, Vitest, Playwright for QA.

**Spec:** `docs/superpowers/specs/2026-11-13-u20-trove-tab-design.md`

## Global Constraints

- AGENTS.md and `frontend/DESIGN.md` bind every task: one `h1` per page, `Card`, `Segmented` (the only radiogroup), `Notice` tones `neutral|warning|danger|success`, `Term` on a Mezo term's first naming (never inside a button, tab, or form label), token colours only (no hex in components), `motion-safe:`, Geist Mono, every guard test green.
- Colour of the risk dots: Low = `accent` (the precedent of today's Healthy badge; `positive` is reserved for signed results by `colour-roles`), Medium = `warning`, High and Liquidatable = `danger`. Plan ruling over the spec's "positive/success", recorded for the reviewer.
- Liquidation risk (spec §3): `liquidatable` if `cr < mcr`; `high` if `cr × 70 / 100 < mcr` (the existing at-risk rule) or `cr × 73 < mcr × 100`; `medium` if `cr × 54 < mcr × 100`; else `low`; null cr → null. Labels round up: "High below 158%", "Low from 204%" at MCR 110%.
- Redemption risk: `debtAhead × 100 > total × 60` → low; `> total × 5` → medium; else high; total 0 → null.
- The at-risk rule (`troveHealth`), `TroveWarning`, and `CR_SAFETY_FLOOR` (160%) do not change. Open and Leverage keep CR ≥ `LEVERAGE_CR_FLOOR` (200%).
- New Trove interest rate: `InterestRateManager.interestRate()` (uint16 bps); addresses testnet `0xD4D6c36A592A2c5e86035A6bca1d57747a567f37`, mainnet `0x4a453700d157717Fe02fB62E7700ED7845048285`.

- Run per task: `cd frontend && npx vitest run <files>`; before the final commit: `npm test && npm run build`.

### Task 1: Risk levels and Trove figures (pure maths)

**Files:**
- Create: `frontend/src/lib/trove/risk.ts`, `frontend/src/lib/trove/risk.test.ts`

**Interfaces:**
- Consumes: `troveHealth(cr, mcr)` from `lib/trove/health.ts`; `TroveState` from `lib/leverage/trove-math.ts`; `ceilDiv`, `WAD` from `lib/math`.
- Produces:
  - `type LiquidationRisk = "low" | "medium" | "high" | "liquidatable"`
  - `type RedemptionRisk = "low" | "medium" | "high"`
  - `liquidationRisk(cr: bigint | null, mcr: bigint): LiquidationRisk | null`
  - `riskLines(mcr: bigint): { high: bigint; medium: bigint }` (1e18 = 100%; high = max(ceilDiv(mcr×100, 73), ceilDiv(mcr×100, 70)), medium = ceilDiv(mcr×100, 54))
  - `redemptionRisk(debtAhead: bigint, total: bigint): RedemptionRisk | null`
  - `liquidationDrop(liquidationPrice: bigint, price: bigint): number` (whole percent, floored; 0 when liquidationPrice ≥ price)
  - `interestDrift(trove: TroveState, mcr: bigint): bigint | null` (MUSD per BTC a year = ceilDiv(principal × interestRateBps × mcr, 10_000 × coll); null when principal, rate, or coll is 0)
  - `multiplyView(trove: TroveState, price: bigint): { netValue: bigint; netBtc: bigint; leverage: bigint | null }` (netValue = coll × price / WAD − debt, may be negative; netBtc = netValue × WAD / price; leverage = (coll × price / WAD) × WAD / netValue, null when netValue ≤ 0)

- [ ] **Step 1: Write the failing tests** (`risk.test.ts`), with the live testnet QA Trove of 13 Nov:

```ts
const MCR = 1_100_000_000_000_000_000n;
const pct = (p: number) => (BigInt(Math.round(p * 1000)) * 10n ** 18n) / 100_000n;
const LIVE: TroveState = { coll: 99_499_760_615_756_376n, principal: 2_419_006_790_000_000_000_000n, interest: 9_821_768_641_358_278_199n, debt: 2_428_828_558_641_358_278_199n, maxBorrowingCapacity: 0n, interestRateBps: 100n };
const PRICE = 69_079_566_890_000_000_000_000n;

it("liquidationRisk bands at MCR 110%", () => {
  expect(liquidationRisk(null, MCR)).toBeNull();
  expect(liquidationRisk(pct(109.9), MCR)).toBe("liquidatable");
  expect(liquidationRisk(pct(150.7), MCR)).toBe("high");
  expect(liquidationRisk(pct(157.1), MCR)).toBe("high");
  expect(liquidationRisk(pct(157.2), MCR)).toBe("medium");
  expect(liquidationRisk(pct(203.7), MCR)).toBe("medium");
  expect(liquidationRisk(pct(203.8), MCR)).toBe("low");
  expect(liquidationRisk(2_829_924_057_233_575_620n, MCR)).toBe("low"); // live QA Trove
});
it("high or liquidatable exactly when troveHealth is not healthy, or Liquity's line is crossed", () => {
  for (let p = 100; p <= 220; p += 0.05) {
    const cr = pct(p);
    const risky = troveHealth(cr, MCR) !== "healthy" || cr * 73n < MCR * 100n;
    expect(["high", "liquidatable"].includes(liquidationRisk(cr, MCR)!)).toBe(risky);
  }
});
it("riskLines rounds the lines up", () => {
  const { high, medium } = riskLines(MCR);
  expect(high).toBe(1_571_428_571_428_571_429n);
  expect(medium).toBe(2_037_037_037_037_037_038n);
});
it("redemptionRisk by share of debt ahead", () => {
  expect(redemptionRisk(0n, 0n)).toBeNull();
  expect(redemptionRisk(428_070_189_937_069_797_584_715_102n, 429_526_842_219_368_806_213_227_836n)).toBe("low"); // live, 99.7%
  expect(redemptionRisk(61n, 100n)).toBe("low");
  expect(redemptionRisk(60n, 100n)).toBe("medium");
  expect(redemptionRisk(6n, 100n)).toBe("medium");
  expect(redemptionRisk(5n, 100n)).toBe("high");
});
it("liquidationDrop floors and never goes negative", () => {
  expect(liquidationDrop(26_851_435_601_166_791_054_040n, PRICE)).toBe(61);
  expect(liquidationDrop(PRICE + 1n, PRICE)).toBe(0);
});
it("interestDrift on the live Trove", () => {
  expect(interestDrift(LIVE, MCR)).toBe(267_428_529_730_415_205_969n);
  expect(interestDrift({ ...LIVE, interestRateBps: 0n }, MCR)).toBeNull();
});
it("multiplyView on the live Trove", () => {
  const v = multiplyView(LIVE, PRICE);
  expect(v.netValue).toBe(4_444_571_810_353_771_885_636n);
  expect(v.netBtc).toBe(64_339_891_091_546_070n);
  expect(v.leverage! / 10n ** 16n).toBe(154n); // 1.54×
  expect(multiplyView({ ...LIVE, debt: LIVE.debt * 100n }, PRICE).leverage).toBeNull();
});
```

(The `pct` helper's rounding may need one wei of care at exact boundaries; adjust the helper, never the expected levels.)
