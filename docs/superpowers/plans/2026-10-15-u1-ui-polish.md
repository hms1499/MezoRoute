# U1 UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade every MezoRoute screen to one consistent "Calm Finance" design system (tokens, Inter, icons, shared components), with a real landing page, a two-column dashboard, a route-page frame with a sticky summary, a visual stepper, and complete loading/empty/error states, without changing any transaction logic.

**Architecture:** Tokens live in `src/lib/ui/tokens.ts` (read by `tailwind.config.ts` and a contrast test). Shared components live in `src/components/ui/`. Screens are rebuilt in order (chrome → landing → dashboard → comparison → route pages → exit/withdraw → confirm/receipt → positions) so every task leaves the app working. Logic stays in `src/lib/**`; the only `src/lib` changes are new display helpers (each unit-tested) and two copy rules.

**Tech Stack:** Next.js 14.2.35 static export, React 18.3.1, Tailwind 3.4.19, `next/font/google` (Inter), `lucide-react` 1.49.0 (new), RainbowKit 2.0.2 theme API, Vitest 5 (node environment, pure modules only), Playwright MCP + keyless mock wallet for QA.

**Spec:** `docs/superpowers/specs/2026-10-15-u1-ui-polish-design.md`

## Global Constraints

- No transaction, quote, gate, read, or send logic changes. `src/lib/**` changes only in the files this plan names.
- Copy rules (`PRODUCT_SPEC.md` §9): never "guaranteed"/"risk-free"/"earn X%" without an on-chain source; "estimated" before confirmation; one sentence per risk before detail; mainnet reference data visually and textually separate from testnet execution data; never imply MezoRoute pays MEZO or gauge rewards.
- Version pins stay exactly as in `AGENTS.md`. The only new dependency is `lucide-react` pinned to `1.49.0` (published 29 Sep 2026).
- Never import Passport, RainbowKit components, or wagmi hooks from a module that `app/layout.tsx` or an `app/**/page.tsx` imports statically (they load through `next/dynamic`, `ssr: false`). `Column` and `ui/*` components without wallet hooks are safe.
- Every text/background colour pair ≥ 4.5:1. Body text ≥ 14 px, footnotes 12 px (`text-xs`), never `text-[10px]`/`text-[11px]`.
- Buttons and inputs ≥ 44 px tall (`min-h-11`) for primary actions; small buttons ≥ 36 px (`min-h-9`). Visible focus ring on every interactive element. All animation behind `motion-safe:` or neutralised by the reduced-motion rule in `globals.css`.
- Works at 360 px wide with no horizontal scroll.
- Every commit: `cd web && npm test && npm run build` pass. Don't run `next build` while `next dev` runs. Never mark `out/` with the iCloud xattr; if `out 2` appears, delete it and rebuild.
- Conventional commits (`feat(web):`, `fix(web):`, `chore(web):`, `docs:`), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Before each commit, check `git status` for iCloud duplicates (`* 2.*`).

`web/src/lib/ui/contrast.ts`:

```ts
function luminance(hex: string): number {
  const value = hex.replace("#", "");
  const [r, g, b] = [0, 2, 4].map((offset) => {
    const channel = parseInt(value.slice(offset, offset + 2), 16) / 255;
    return channel <= 0.03928 ? channel / 12.92 : ((channel + 0.055) / 1.055) ** 2.4;
  });
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

/** WCAG 2 contrast ratio between two #RRGGBB colours, from 1 to 21. */
export function contrastRatio(a: string, b: string): number {
  const [light, dark] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (light + 0.05) / (dark + 0.05);
}
```

```tsx
import { ExternalLink, LoaderCircle } from "lucide-react";
import Link from "next/link";
import type { ButtonHTMLAttributes, ReactNode } from "react";
import { cx } from "@/lib/ui/cx";

type Variant = "primary" | "secondary" | "ghost" | "danger";
type Size = "md" | "sm";

const BASE =
  "inline-flex items-center justify-center gap-2 rounded-full font-semibold transition-colors duration-150 ease-out disabled:cursor-not-allowed disabled:opacity-50 aria-disabled:cursor-not-allowed aria-disabled:opacity-50";
const VARIANTS: Record<Variant, string> = {
  primary: "bg-accent text-white hover:bg-accent/90 active:bg-accent/80",
  secondary: "border border-line bg-white text-accent hover:bg-accent-soft",
  ghost: "text-accent hover:bg-accent-soft",
  danger: "bg-danger text-white hover:bg-danger/90",
};
const SIZES: Record<Size, string> = { md: "min-h-11 px-5 text-sm", sm: "min-h-9 px-3.5 text-xs" };

export function buttonClass(variant: Variant = "primary", size: Size = "md", className?: string): string {
  return cx(BASE, VARIANTS[variant], SIZES[size], className);
}

type Common = { variant?: Variant; size?: Size; className?: string; children: ReactNode };

/** The app's one button style; `loading` shows a spinner and disables it. */
export function Button({
  variant,
  size,
  className,
  loading = false,
  disabled,
  type = "button",
  children,
  ...rest
}: Common & { loading?: boolean } & Omit<ButtonHTMLAttributes<HTMLButtonElement>, "className" | "children">) {
  return (
    <button
      type={type}
      disabled={disabled || loading}
      aria-busy={loading || undefined}
      className={buttonClass(variant, size, className)}
      {...rest}
    >
      {loading && <LoaderCircle aria-hidden className="h-4 w-4 motion-safe:animate-spin" />}
      {children}
    </button>
  );
}

/** A link styled as a button: `disabled` renders an inert span, `external` opens a new tab. */
export function ButtonLink({
  href,
  external = false,
  disabled = false,
  variant,
  size,
  className,
  children,
}: Common & { href: string; external?: boolean; disabled?: boolean }) {
  const classes = buttonClass(variant, size, className);
  if (disabled) {
    return (
      <span aria-disabled="true" className={classes}>
        {children}
      </span>
    );
  }
  if (external) {
    return (
      <a href={href} target="_blank" rel="noreferrer" className={classes}>
        {children}
        <ExternalLink aria-hidden className="h-3.5 w-3.5" />
      </a>
    );
  }
  return (
    <Link href={href} className={classes}>
      {children}
    </Link>
  );
}
```

```tsx
import type { ReactNode } from "react";
import { cx } from "@/lib/ui/cx";

/** A white surface with an optional header; `reference` marks mainnet reference data (dashed, muted). */
export function Card({
  title,
  subtitle,
  aside,
  variant = "default",
  headingLevel = 2,
  id,
  className,
  children,
}: {
  title?: ReactNode;
  subtitle?: ReactNode;
  aside?: ReactNode;
  variant?: "default" | "reference";
  headingLevel?: 1 | 2;
  id?: string;
  className?: string;
  children?: ReactNode;
}) {
  const Heading = headingLevel === 1 ? "h1" : "h2";
  return (
    <section
      id={id}
      className={cx(
        variant === "reference" ? "rounded-2xl border border-dashed border-line bg-canvas p-5" : "card",
        "scroll-mt-6",
        className,
      )}
    >
      {(title || aside) && (
        <header className="flex flex-wrap items-start justify-between gap-x-3 gap-y-1">
          <div className="min-w-0">
            {title && (
              <Heading className={cx("font-semibold tracking-tight", headingLevel === 1 ? "text-xl" : "text-base")}>{title}</Heading>
            )}
            {subtitle && <p className="mt-0.5 text-sm text-muted">{subtitle}</p>}
          </div>
          {aside}
        </header>
      )}
      {children}
    </section>
  );
}

/** A divided part of a card. */
export function CardSection({ className, children }: { className?: string; children: ReactNode }) {
  return <div className={cx("mt-4 border-t border-line pt-4", className)}>{children}</div>;
}
```

```ts
const trim = (path: string) => (path.length > 1 ? path.replace(/\/+$/, "") : path);

/** Whether a header link is the current page; paths compare without the trailing slash (`trailingSlash: true`). */
export function isCurrentPath(pathname: string | null, href: string): boolean {
  if (pathname === null) return false;
  const current = trim(pathname);
  const target = trim(href);
  if (target === "/") return current === "/";
  return current === target || current.startsWith(`${target}/`);
}
```

```ts
import { lpHistoryLine } from "@/lib/compare/view";
import { formatPercent, formatToken } from "@/lib/format";
import type { MainnetReferenceData } from "./load";

export type LandingLive =
  | { kind: "loading" }
  | { kind: "hidden" }
  | { kind: "data"; poolValue: string; lpFees: string | null; spDeposits: string; spShare: string };

/** The landing page's live mainnet figures: a skeleton while loading, nothing on error (the page stays complete). */
export function landingLive(data: MainnetReferenceData | undefined, error: Error | null): LandingLive {
  if (data) {
    const view = referenceView(data.reference);
    return {
      kind: "data",
      poolValue: `${formatToken(view.poolTvl, 18, 0)} MUSD`,
      lpFees: data.backtests?.lp ? lpHistoryLine(data.backtests.lp) : null,
      spDeposits: `${formatToken(data.reference.spDeposits, 18, 0)} MUSD`,
      spShare: formatPercent(view.spShare, 1),
    };
  }
  return error ? { kind: "hidden" } : { kind: "loading" };
}
```

```ts
import type { Step } from "@/lib/tx/stepper";

export type StepVisual = "done" | "failed" | "wallet" | "confirming" | "current" | "upcoming";

/** How a stepper node looks: its status once it moved, else current (the step to act on) or upcoming. */
export function stepVisual(step: Step<string>, index: number, active: number): StepVisual {
  switch (step.status) {
    case "done":
      return "done";
    case "failed":
      return "failed";
    case "awaiting-wallet":
      return "wallet";
    case "submitted":
      return "confirming";
    case "idle":
      return index === active ? "current" : "upcoming";
  }
}
```

```ts
export type Countdown = { secondsLeft: number; remaining: number; expired: boolean };

/** Time left on a quote: whole seconds (rounded up) for the text, 0–1 for the bar; expired matches the gate (age > TTL). */
export function quoteCountdown(now: number, fetchedAt: number, ttlMs: number): Countdown {
  const age = Math.max(0, now - fetchedAt);
  const left = Math.max(0, ttlMs - age);
  return { secondsLeft: Math.ceil(left / 1000), remaining: left / ttlMs, expired: age > ttlMs };
}
```

```tsx
function Timeline({ state }: { state: "pending" | "confirmed" | "failed" }) {
  const stages = [
    { label: "Submitted", done: true },
    { label: "Confirming", done: state !== "pending", current: state === "pending" },
```
